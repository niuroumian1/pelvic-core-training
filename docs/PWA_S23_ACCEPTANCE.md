## S23 测试连接方法

推荐使用 USB + ADB 端口转发：

1. 手机开启“开发者选项”和“USB 调试”。
2. 用支持数据传输的 USB 线连接电脑。
3. 在手机弹窗中允许这台电脑进行 USB 调试。
4. 在电脑执行：

```powershell
adb devices -l
adb reverse tcp:4173 tcp:4173
```

5. 在项目的 `pwa` 目录启动：

```powershell
npm run dev -- --host 127.0.0.1 --port 4173
```

6. 手机浏览器打开 `http://127.0.0.1:4173/`。

该方法不依赖局域网 Network 地址。

## PWA 安装说明

USB 转发的 HTTP 页面适合功能和布局调试，但 Android 上完整的 PWA 安装、Service Worker 与离线能力应使用 HTTPS 地址验证。

当前 Manifest 只配置了 SVG 图标。Chrome 通常可以读取，但正式 Android 安装验收前建议补充 192 × 192、512 × 512 PNG 和 maskable 图标。

GitHub Pages 发布后的 HTTPS 验收地址：

```text
https://niuroumian1.github.io/pelvic-core-training/
```

线上审查步骤：

1. 联网打开地址，完成一次训练并确认历史记录。
2. 使用浏览器菜单安装应用/添加到主屏幕。
3. 从主屏幕启动，确认应用名称、图标与独立窗口显示。
4. 联网刷新一次后关闭应用，断开网络并冷启动。
5. 确认应用外壳可以离线打开，之前的本地记录仍存在。
