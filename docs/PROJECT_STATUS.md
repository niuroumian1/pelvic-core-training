# 项目当前状态

> 更新时间：2026-07-24  
> 当前开发主线：`pwa/`  
> 当前版本：V0.1 Demo

## 1. 项目边界

当前目标是验证“男性盆底肌训练过程游戏化、动画化”的移动端体验。项目暂不
商业化，也不实现登录、社交、商城、云同步、完整 RPG、角色或多运动系统。

仓库中同时存在两套实现：

- `pwa/`：当前主线，React + TypeScript + Vite PWA。
- `lib/`、`android/`、`web/`、`test/`：早期 Flutter/Android 原型，暂时保留，
  但不作为当前 PWA 开发依据。

后续修改默认只进入 `pwa/`。若要修改或删除 Flutter 原型，必须先明确说明范围。

## 3. 已实现功能

### 页面与导航

- `/`：首页，显示今日状态、训练主题、连续天数和开始入口。
- `/training`：训练页，自动运行完整训练流程。
- 训练页返回按钮会暂停训练并打开退出确认；继续会从原位置恢复，确认退出不会保存完成记录。
- `/history`：本地训练记录、完成次数、连续天数和总经验。
- 未知路径自动返回首页。

### 训练协议

当前盆底肌协议位于 `src/engine/kegelProtocol.ts`：

```text
READY 3 秒
CONTRACT 5 秒
HOLD 3 秒
RELAX 5 秒
```

- 每次训练共 3 组。
- READY 只在整次训练开始时执行一次。
- 后续组从 CONTRACT 开始。
- 完成第三组后进入 SUCCESS。

### 训练引擎

`src/engine/trainingEngine.ts` 是与 React、动画和存储无关的分阶段计时核心：

- 协议提供阶段、时长和组数。
- 引擎输出当前阶段、剩余时间、阶段进度和组数。
- 使用真实经过时间推进，浏览器后台降频后返回时可能跨越多个阶段。
- React 通过 `useTrainingSession` 订阅快照。

### Energy Core 动画

- `AnimationStage` 提供与主题无关的动画舞台。
- `animationManager.tsx` 根据 `animationId` 选择动画提供者。
- 当前只注册 `energy-core`。
- CONTRACT 压缩聚合、HOLD 稳定维持、RELAX 释放恢复。
- 倒计时、动作和提示位于动画下方，动画保持视觉中心。
- 支持 `prefers-reduced-motion`。

### 本地记录

`StorageService` 通过接口封装 `localStorage`：

- 存储键：`pelvic-core-training:data`
- 数据版本：`schemaVersion: 1`
- 保存完成会话、时间、组数、经验和难度反馈。
- 计算完成次数、连续天数、总经验和当前等级。
- 同一会话 ID 幂等保存，避免重复记录。

数据仅属于当前浏览器设备；清除网站数据会删除记录。

### 移动端平台能力

- Web Vibration：已接入训练阶段切换。
- Web Notification：接口和 Web 实现已存在，但没有用户入口，也不会主动申请权限。
- PWA 安装提示：首页仅在浏览器触发安装事件时显示安装按钮。
- Capacitor：尚未接入；平台接口可在未来替换为 Haptics 和 Local Notifications。

### AI

- `AIService` 已定义聊天和训练分析接口。
- 预留路径：
  - `/api/ai/chat`
  - `/api/ai/training-analysis`
- 当前只返回模拟数据，不发送真实网络请求，也没有用户界面入口。

## 4. 当前自动化测试范围

- 训练初始状态和阶段转换。
- 三组循环与 SUCCESS。
- 跨阶段剩余时间结转。
- 本地会话幂等保存。
- 连续训练天数计算。
- 用户反馈更新。
- AI 模拟接口和预留路径。
- React 退出确认组件行为，以及训练页路由与训练协调。

尚未自动覆盖：

- Energy Core 视觉回归。
- Service Worker 离线行为。
- PWA 安装流程。
- 通知权限。
- PWA 安装和离线冷启动。

这些项目需要浏览器或真机审查，不能用当前单元测试结果代替。

## 5. 已知限制与风险

1. 训练进入后台后仍按真实时间推进，返回时可能跳过阶段。
2. 浏览器或系统返回键的拦截仍不在 V0.1 范围内。
3. PWA 完整安装需要安全来源；局域网 HTTP 通常无法验证安装。
4. 本地记录没有迁移到 IndexedDB、SQLite 或云端。
5. 通知和 AI 目前只是接口预留，不是已交付用户功能。
6. 当前 PWA 图标为 SVG；正式发布前应验证目标浏览器和 Android 安装图标表现。
7. 根目录的 Android 真机测试计划针对旧 Flutter 原型，其中部分流程、积分和命令
   不适用于当前 PWA。
8. 已在 2026-07-24 建立首个 Git 基线提交 `e366c39`。
