# 产品说明

## 产品定位

“男性核心训练 Demo”是一款移动端优先的游戏化训练 PWA，用动画反馈帮助用户完成盆底肌训练。

当前项目用于验证训练节奏、视觉反馈和移动端操作体验，暂不商业化。

## V0.1 目标

交付一个简单、稳定、可运行且容易迭代的训练 Demo：

- 首页展示今日 3 组训练并提供开始入口
- 完成 `READY → CONTRACT → HOLD → RELAX` 的训练流程
- 使用 Energy Core 动画反馈训练阶段
- 完成后展示本次训练结果
- 在设备本地保存训练记录
- 支持手机浏览器运行和 PWA 安装

## V0.1 不包含

- 登录、社交、商城和云同步
- 多运动训练
- 真实 AI 服务
- RPG、角色、装备、地图和任务系统
- 复杂训练计划和健康诊断

## 开发优先级

1. 核心训练体验
2. 动画反馈
3. 数据记录
4. 扩展架构

## 成功标准

- 用户无需说明即可开始并完成一次训练
- 训练阶段、剩余时间和当前动作清晰可辨
- 动画与训练节奏同步，且在常见手机尺寸下流畅运行
- 刷新或离线打开后仍可进入应用
- 核心训练逻辑不依赖具体页面、动画或浏览器 API
