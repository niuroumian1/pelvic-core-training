# 未来功能

本文记录方向，不代表当前开发范围，也不要求提前创建代码模块。

## 运动系统

未来可能支持：

- 盆底肌训练
- 俯卧撑
- 深蹲
- 引体向上
- 拉伸
- 呼吸训练

不同运动可采用时间型、次数型或保持型训练协议。V0.1 只实现盆底肌时间训练。

## 动画主题

未来可以增加：

- 挤压气球
- 花朵绽放
- 锻造
- 机关解锁
- 角色动作

动画主题通过 `AnimationProvider` 扩展，不进入训练状态机。

## AI 能力

未来可能包括：

- AI 训练总结
- 个性化训练建议
- 周训练计划
- AI 陪练

预留接口方向：

- `/api/ai/chat`
- `/api/ai/training-analysis`

V0.1 只允许使用本地模拟返回，不请求真实 AI。

## 成长与习惯系统

未来可能包括：

- 经验值和等级
- 成就
- 连续训练奖励
- 角色成长和陪伴
- 训练基地

V0.1 的 `经验 +10` 和连续训练次数仅作为完成反馈及基础记录，不实现完整 RPG 规则。

## 数据与平台

未来可能从 `localStorage` 迁移到：

- IndexedDB
- Capacitor SQLite
- 云同步数据库

未来可以使用 Capacitor Haptics 和 Local Notifications 替换对应的 Web 平台实现。
