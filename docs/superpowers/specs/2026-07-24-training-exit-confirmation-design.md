# 训练中退出确认设计

日期：2026-07-24  
状态：已实施并完成最终复审修复

## 目标

降低用户在训练过程中误触返回按钮导致训练直接中断的风险。

弹出退出确认时暂停训练；用户选择继续后，从弹窗出现前的阶段和剩余时间恢复。确认退出不保存完成记录，不增加经验或连续训练天数。

## 当前范围

本轮只处理训练页面左上角的“返回首页”按钮。

不处理以下内容：

- 浏览器或 Android 系统返回键拦截
- 刷新、关闭标签页和浏览器崩溃恢复
- 未完成训练记录
- 云端同步
- 通用路由阻塞框架

## 用户流程

### 打开确认面板

1. 用户正在 READY、CONTRACT、HOLD 或 RELAX 阶段。
2. 用户点击左上角返回按钮。
3. 页面阻止立即导航。
4. 训练状态机暂停。
5. 页面显示退出确认面板。

### 继续训练

1. 用户点击“继续训练”。
2. 确认面板关闭。
3. 状态机重新建立计时基准。
4. 训练从暂停前的阶段、组数、剩余时间继续。

弹窗停留时间不得计入训练进度。

### 结束训练

1. 用户点击“结束训练”。
2. 状态机保持停止，并由训练页面卸载时完成清理。
3. 页面返回首页。
4. 不写入训练完成记录，不增加经验、连续训练天数或完成次数。

### 训练完成

SUCCESS 页面继续使用现有结果页，不显示退出确认。

## 技术设计

### TrainingEngine

在通用计时训练引擎增加明确的暂停状态：

- `pause()`：清除当前定时器，保留训练快照。
- `resume()`：从当前快照继续，并将 `lastTickAt` 重设为恢复时刻。
- `isPaused()`：返回引擎当前是否处于人工暂停状态。

行为约束：

- 未启动或已经暂停时重复调用 `pause()`必须安全。
- 正在运行时重复调用 `resume()`不得创建多个定时器。
- SUCCESS 状态不得重新启动。
- 暂停期间经过的真实时间不得被下一次 tick 计入。
- 现有 `stop()`继续用于组件卸载和终止调度，不承担用户可恢复暂停的语义。

引擎接口保持运动无关，不引用 Kegel、页面、弹窗或动画。

### useTrainingSession

Hook 继续拥有引擎实例及生命周期，向页面返回：

- 当前训练快照
- `pause`
- `resume`
- `isPaused`

组件卸载时继续取消订阅并停止引擎。

### ExitConfirmation

新增独立展示组件，职责仅限：

- 显示标题和简短说明
- 提供“继续训练”和“结束训练”按钮
- 提供可访问的对话框语义
- 将用户操作通过回调交给页面

该组件不直接操作路由、状态机、本地存储或浏览器 API。

### Training 页面

训练页负责协调：

- 返回按钮改为页面内按钮，不再直接使用导航链接。
- 打开确认面板时调用 `pause()`。
- 继续训练时调用 `resume()`。
- 结束训练时使用 React Router 导航到首页。
- 只有训练达到 SUCCESS 时才沿用现有完成记录保存逻辑。

## 视觉与交互

- 使用与当前男性健康训练空间一致的深色、圆角、柔和层级。
- 背景增加半透明遮罩，保留暂停瞬间的能量核心画面。
- 确认面板从屏幕底部呈现，兼容 `env(safe-area-inset-bottom)`。
- “继续训练”为主要按钮。
- “结束训练”为次要危险操作，不使用高饱和警告红色。
- 面板打开后，焦点优先落在“继续训练”。
- 对话框提供可读标题，并使用 `role="dialog"` 和 `aria-modal="true"`。

## 测试策略

### 状态机单元测试

- 暂停期间时间不推进。
- 恢复后只计算恢复后的时间。
- 重复暂停和恢复不会创建多个定时器。
- SUCCESS 状态不能恢复。

### 页面行为测试

- 点击返回按钮显示确认面板。
- 点击“继续训练”关闭面板并保留当前训练状态。
- 点击“结束训练”返回首页。
- 未完成退出不会写入完成记录。

如果当前测试环境不适合完整页面测试，本轮至少完成状态机测试，并通过浏览器执行页面行为验证；页面测试环境作为后续自动化测试阶段的明确任务，不为本功能引入大规模测试框架重构。

### 手工移动端验收

在 Samsung Galaxy S23 上检查：

- 确认面板不被底部手势区遮挡。
- 暂停后数字、阶段和动画停留在当前状态。
- 等待五秒后选择继续，不发生阶段跳跃。
- 确认退出后首页统计和历史记录不变化。
- 连续打开、取消确认三次，训练仍能继续且没有重复震动。

## 验收标准

- 用户点击训练页左上角返回按钮时不会立即退出。
- 确认面板打开期间训练完全暂停。
- 继续训练后从原位置恢复。
- 结束训练返回首页且不保存记录。
- 现有完整训练、经验、连续天数、反馈和历史记录行为不受影响。
- 单元测试和生产构建通过。
